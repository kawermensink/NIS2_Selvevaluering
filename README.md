# NIS2 Selvevaluering (Gap-analyse)
 
An Excel self-assessment tool that helps organisations covered by the Danish NIS2 Act see how far they are in implementing the cybersecurity measures in § 6. Use it as a gap analysis and as the basis for a prioritised action plan.
 
The workbook is in Danish and sector-neutral. It is based on the Danish Agency for Civil Protection's (Styrelsen for Samfundssikkerhed, SAMSIK) guidance on implementing cybersecurity measures and on Commission Implementing Regulation (EU) 2024/2690.
 
## What's inside
 
| Sheet | Purpose |
|---|---|
| **Introduktion** | Overview of the tool and its sheets |
| **Virksomhedsoplysninger** | Company name, CVR number and assessment period |
| **Selvevalueringsværktøj** | The assessment itself: 149 requirements with description, guidance notes, a 1–4 score and a documentation reference |
| **Selvevaluering_beskrivelse** | Explains each score, with an example action plan, and the difference between SKAL and BØR |
| **Selvevaluering_output** | Calculated output: average score per area plus charts (not for editing) |
 
The requirements follow the 10 areas in § 6, stk. 1:
 
1. Politik for informationssystemsikkerhed og risikostyring
2. Håndtering af hændelser · logning og monitorering
3. Driftskontinuitet · backup · redundans · krisestyring
4. Forsyningskædesikkerhed
5. Erhvervelse, udvikling og vedligeholdelse · håndtering af sårbarheder
6. Vurdering af effektivitet · tekniske tests
7. Cyberhygiejnepraksisser · cybersikkerhedsuddannelse
8. Kryptografi
9. Personalesikkerhed · adgangskontrol · forvaltning af aktiver
10. Multifaktorautentificering · nødkommunikationssystemer
## Scoring
 
Each requirement is scored from a dropdown menu:
 
| Value | Meaning |
|---|---|
| 1 | Not implemented or planned |
| 2 | Planned, but not implemented |
| 3 | Partially implemented |
| 4 | Fully implemented |
| Ikke relevant | Not applicable (requires a documented justification) |
 
Each requirement is also marked as one of two types:
 
- **SKAL** (requirement): you must be able to show documentation that it is in place.
- **BØR** (recommendation): if you don't implement it, you must be able to explain why to the supervisory authority, taking into account the state of the art, cost and your risks.
## Getting started
 
1. Download `NIS2_Selvevaluering.xlsx` and open it in Excel.
2. Fill in **Virksomhedsoplysninger**.
3. Go through **Selvevalueringsværktøj**. Score each requirement with help from **Selvevaluering_beskrivelse**, and note where the documentation can be found.
4. Review **Selvevaluering_output** to see your averages per area and prioritise the lowest scores, starting with SKAL requirements.
5. Repeat the assessment at least annually and after significant changes.
